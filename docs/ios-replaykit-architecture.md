# KEMOR — iOS ReplayKit Broadcast Extension & Free Fire Audio Guide

## 1. Executive Summary & Feasibility Assessment

### Can a Web App Alone Capture Free Fire Game Audio on iOS?
**NO.** Under Apple's iOS security architecture, Safari, Chrome for iOS, and Progressive Web Apps (PWAs) run inside a strict WebKit sandbox. The WebRTC `navigator.mediaDevices.getDisplayMedia` API on iOS:
1. Can only capture web contents or basic screen pixels when explicitly enabled by iOS.
2. **Cannot** access system audio buffers or capture audio output generated by another third-party application (such as Garena Free Fire).

### What Is Strictly Required?
To capture internal game audio and stream it to a real-time squad voice room, Apple requires:
1. **A Native iOS Application or Wrapper** (built with Swift/SwiftUI or wrapped using **Capacitor** around the KEMOR web app).
2. **A Broadcast Upload Extension Target** utilizing Apple's **ReplayKit framework** (`RPBroadcastSampleHandler`).
3. An **App Group** (`group.com.kemor.app`) shared between the main app and the extension.

## 2. Audio Routing Architecture: Game Sound to Voice Room

When the user activates screen recording/broadcast from the iOS Control Center and selects **KEMOR**:

```
[ Free Fire Gameplay ]
         │ (Internal Game Audio)
         ▼
[ iOS System Audio Engine ]
         │
         ▼
[ KEMOR Broadcast Upload Extension (ReplayKit) ]
   ├── processSampleBuffer(..., .audioApp) ──> Raw PCM Audio
   ├── processSampleBuffer(..., .video)    ──> 60 FPS Video Frames
   └── processSampleBuffer(..., .audioMic) ──> Hardware Microphone
         │
         ▼
[ WebRTC Audio Track / Streaming Client ]
         │ (Encrypted SRTP Audio Stream)
         ▼
[ KEMOR Voice Room Server (WebSocket / SFU) ]
         │
         ▼
[ Teammates Hear Free Fire Game Sound + Squad Voice ]
```

### The Sample Buffer Types
Inside `RPBroadcastSampleHandler`, iOS provides three distinct buffer streams:
* `RPSampleBufferType.audioApp`: The internal game audio produced by Free Fire.
* `RPSampleBufferType.audioMic`: The hardware microphone audio (if system mic is enabled in the broadcast picker).
* `RPSampleBufferType.video`: Video frames rendered by the screen at up to 60 FPS.

## 3. Preserving Two-Way Voice Communication & Resolving the iOS Mic Conflict

### The Free Fire Audio Session Conflict
iOS manages audio hardware using `AVAudioSession`. When two apps request the microphone simultaneously, iOS gives priority to the foreground active app or severely attenuates other audio.

### The Proven Tournament Setup
1. **Inside Free Fire:**
   * Go to **Settings → Sound → Voice**.
   * Turn **Microphone OFF**, but keep **Sound Effects & Music ON**.
   * *Why:* This stops Free Fire from seizing exclusive control of `AVAudioSessionCategoryPlayAndRecord`, allowing KEMOR to maintain clear squad voice comms.
2. **Inside KEMOR:**
   * KEMOR manages the two-way voice channel:
     * Plays teammates' voices into your headset.
     * Records your voice and streams it to your squad.
3. **Through ReplayKit:**
   * The broadcast extension intercepts Free Fire's `.audioApp` stream and relays it into the squad room.
   * Your teammates hear **both** your voice and your Free Fire footsteps/gunfire.

## 5. Complete Swift Implementation

### File: `SampleHandler.swift` (Inside the Broadcast Upload Extension)

```swift
import ReplayKit
import AVFoundation

class SampleHandler: RPBroadcastSampleHandler {

    private var isStreaming = false
    private let appGroupId = "group.com.kemor.app"

    override func broadcastStarted(withSetupInfo setupInfo: [String : NSObject]?) {
        // User started broadcast from iOS Control Center
        isStreaming = true
        NSLog("[KEMOR] Broadcast extension started successfully.")
    }

    override func broadcastPaused() {
        // User paused broadcast
    }

    override func broadcastResumed() {
        // User resumed broadcast
    }

    override func broadcastFinished() {
        // User stopped broadcast
        isStreaming = false
        NSLog("[KEMOR] Broadcast extension finished.")
    }

    override func processSampleBuffer(_ sampleBuffer: CMSampleBuffer, with sampleBufferType: RPSampleBufferType) {
        guard isStreaming else { return }

        switch sampleBufferType {
        case .video:
            // Process 60 FPS video frame
            handleVideoSample(sampleBuffer)

        case .audioApp:
            // CRITICAL: Captures internal Free Fire game sound (footsteps, gunshots)
            handleGameAudioSample(sampleBuffer)

        case .audioMic:
            // Microphone captured by iOS system broadcast
            handleMicAudioSample(sampleBuffer)

        @unknown default:
            break
        }
    }

    private func handleGameAudioSample(_ sampleBuffer: CMSampleBuffer) {
        // 1. Extract linear PCM audio data
        guard let blockBuffer = CMSampleBufferGetDataBuffer(sampleBuffer) else { return }
        var lengthAtOffset = 0
        var totalLength = 0
        var dataPointer: UnsafeMutablePointer<Int8>?

        CMBlockBufferGetDataPointer(
            blockBuffer,
            atOffset: 0,
            lengthAtOffsetOut: &lengthAtOffset,
            totalLengthOut: &totalLength,
            dataPointerOut: &dataPointer
        )

        guard let data = dataPointer, totalLength > 0 else { return }

        // 2. Transmit audio packet to KEMOR WebRTC / WebSocket voice room
        // In production: Resample to 48kHz mono PCM and dispatch via WebRTC Audio Track
        KemorAudioBridge.shared.sendAudioPacket(data: Data(bytes: data, count: totalLength), type: .gameAudio)
    }

    private func handleMicAudioSample(_ sampleBuffer: CMSampleBuffer) {
        // Forward player mic audio
    }

    private func handleVideoSample(_ sampleBuffer: CMSampleBuffer) {
        // Forward 60 FPS screen share frame
    }
}
```

## 6. Beginner Roadmap: From Google AI Studio & iPhone to Native iOS

Because Google AI Studio runs in a Linux container and you are using an iPhone:
1. **Phase 1 (Available in Web / Today):**
   * KEMOR's web app handles WebRTC squad voice, mic DSP (noise suppression & echo cancellation), screen sharing, and permanent channel management.
   * Free Fire players can already hear game sound and squad voice simultaneously on iPhone by adding KEMOR to Home Screen (PWA mode) and muting Free Fire's in-game mic.
2. **Phase 2 (Packaging into Native iOS App):**
   * Export the web project and run `npx @capacitor/core` and `npx @capacitor/ios`.
   * Open the generated Xcode project on any Mac (or via a free GitHub Actions macOS runner).
   * Add the **Broadcast Upload Extension** target using the code above.
3. **Phase 3 (Testing on iPhone):**
   * Sign the app with a free Apple Developer account.
   * Deploy to your iPhone via Xcode or Apple TestFlight.
